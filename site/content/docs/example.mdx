```md
# Spec Analysis: Add Rate Limiting

## Solution

**Problem:** The API accepts unbounded requests per client. Cap each client IP at 60 requests per minute, with `/health` exempt so probes never get throttled.

**Proposed Solution:**

An in-process fixed-window counter keyed by client IP, applied in `createApp` request handler before routing. A request to `/health` bypasses it. Any other request increments the counter for its IP; the 61st request within the window gets `429` with a `Retry-After` header until the window ends.

**Key Components:**
- **Limiter (`src/rate-limit.js`):** `createRateLimiter({ limit, windowMs, now })` returning `{ check(key) -> { allowed, retryAfterSec }, sweep(), }`. Holds a `Map<ip, { count, resetAt }>`.
- **Wiring (`src/app.js`):** calls the limiter first, after the `/health` check; starts an unref'd sweep timer, cleared when the server closes.

## Technical Approach

**Findings (question, method, result):**
- Is there a proxy / multiple instances? Read `README.md`: "single instance, no proxy in front" → in-memory state is correct; `req.socket.remoteAddress` is the real client IP.
- How are routes matched? Read `src/app.js`: exact `req.method`/`req.url` comparison, no framework, no middleware chain; `/health` is `GET` and `req.url === "/health"`.
- Runtime / deps? `package.json`: ESM, no dependencies, `node --test`; Node v26 locally. No dependency will be added.

**Technical Decisions:**
- **Fixed window, not sliding:** simplest, O(1) memory per IP. Accepted trade-off: up to 120 requests can pass across a window boundary.
- **Key = `req.socket.remoteAddress` as-is:** `X-Forwarded-For` is never read (spoofable, and there is no proxy). IPv6 is keyed per full address; no /64 grouping; no IPv4-mapped normalization.
- **Exemption:** `req.url === "/health"` exactly, any method, mirroring the existing route match. `/health?x=1` is not exempt.
- **Scope of counting:** every non-exempt request counts, including those answering 404.
- **Rejection response:** status `429`, header `Retry-After: <seconds>` where seconds = `max(1, ceil((resetAt - now) / 1000))`, JSON body `{"error":"rate limit exceeded"}` (same shape as the existing 404). No `X-RateLimit-*` headers.
- **Config:** constants `limit = 60`, `windowMs = 60000` as defaults of `createApp`'s options; no env vars. `createApp({ rateLimit: { limit, windowMs, now } })` allows tests to inject small limits and a fake clock.
- **Memory bound:** a sweep every `windowMs` deletes entries whose `resetAt <= now`; the timer is `unref()`ed and cleared on server `close`. Lazy reset on access handles expired entries for returning IPs.

**Architecture Changes:** one new module; handler gains a guard at its start.

**Data Model Changes:** none (state is in memory, lost on restart; acceptable).

**API Changes:** any endpoint except `/health` may now return `429` as specified above.

## Scope

**In Scope:**
- Per-IP limiter, `/health` exemption, `429` + `Retry-After`, tests, README note.

**Out of Scope:**
- Shared/distributed state, proxy/`X-Forwarded-For` support, per-route or per-user limits, `X-RateLimit-*` headers, env configuration, metrics/logging of rejections.

**Phases:**

**Phase 1: Limiter**
- Module with injectable clock, window reset, sweep.

**Phase 2: Wiring**
- Guard in `createApp`, `/health` bypass, timer lifecycle.

**Phase 3: Tests and docs**
- Deterministic tests, README note.

**Success Criteria:**
- [ ] 60 requests from one IP in a window succeed; the 61st returns 429 with integer `Retry-After` ≥ 1
- [ ] After the window elapses, the IP is served again
- [ ] `/health` returns 200 after the IP is limited, and never consumes quota
- [ ] Counters are per IP (two addresses are independent)
- [ ] Expired entries are removed by the sweep; the timer does not keep the process alive and is cleared on close
```

## The implementation

`/theway:develop` implemented the tasks in the session and ticked them. First `src/rate-limit.js`:

```js
export function createRateLimiter({ limit, windowMs, now }) {
  const entries = new Map();

  return {
    check(key) {
      const t = now();
      let entry = entries.get(key);
      if (!entry || t >= entry.resetAt) {
        entry = { count: 0, resetAt: t + windowMs };
        entries.set(key, entry);
      }
      entry.count++;
      if (entry.count <= limit) return { allowed: true, retryAfterSec: 0 };
      return { allowed: false, retryAfterSec: Math.max(1, Math.ceil((entry.resetAt - t) / 1000)) };
    },
    sweep() {
      const t = now();
      for (const [key, entry] of entries) {
        if (entry.resetAt <= t) entries.delete(key);
      }
    },
    size: () => entries.size,
  };
}
```
