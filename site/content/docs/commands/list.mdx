---
title: /theway:list
description: List the active and archived changes of the current project
---

## Usage

```text
/theway:list
```

## Example

In `my-api`, after the [series](../examples/series.mdx) and the archive of `add-rate-limiting`:

```text
/theway:list
```

```text
theway changes — -home-you-code-my-api

Active changes

  add-user-auth-01     2 files   3/3 tasks done
  add-user-auth-02     2 files   3/3 tasks done
  add-user-auth-03     2 files   3/3 tasks done

Archived changes (1)

  YYYY-MM-DD-add-rate-limiting

Summary: 3 active change(s), 1 archived.
```

## Steps

It runs the CLI, which derives the [project key](../concepts/changes.mdx#project-key) from the current directory, and shows the output as it is:

```bash
theway list
```

For each change shown as `invalid: …`, it runs [`theway change <change-id>`](../cli.mdx#change) and shows the error lines it prints; it does not edit the change's `change.yaml` unless you ask.

## Output

Each line of `theway list`, as in the example above:

- An active change shows its number of files (every regular, non-hidden file in its folder) and its tasks done out of all the tasks of its `change.yaml`, or `invalid: <error>` when that file is missing or invalid.
- Archived changes are listed by folder name.

See [`theway list`](../cli.mdx#list).
