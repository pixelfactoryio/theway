---
title: /theway:setup
description: Install or update theway from a Claude Code session
---

It runs the same command as [Installation](../installation.mdx#install-and-update).

## Usage

```text
/theway:setup
```

## Steps

1. Runs the installer:

   ```bash
   npx --yes github:pixelfactoryio/theway install
   ```

2. If the installer exits non-zero, it shows the installer's stderr and stops.
3. Otherwise it reports the installer's last line and tells you to run `/reload-plugins`.

## Output

The files listed in [What install writes](../installation.mdx#what-install-writes). The other commands send you here when `~/.theway/config.yaml` is missing.
