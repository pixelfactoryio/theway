---
title: Contributing
description: How to report issues and contribute to theway.
---

Bug reports, feature requests and pull requests are welcome. Start a larger change with an issue, so the approach is agreed before the code is written.

- [CONTRIBUTING.md](https://github.com/pixelfactoryio/theway/blob/main/CONTRIBUTING.md): development setup, repo layout, testing a local build, commit and PR conventions, and the release process.
- [CODE_OF_CONDUCT.md](https://github.com/pixelfactoryio/theway/blob/main/CODE_OF_CONDUCT.md): the code of conduct.
- [SECURITY.md](https://github.com/pixelfactoryio/theway/blob/main/SECURITY.md): how to report a vulnerability. Never report one in a public issue.
