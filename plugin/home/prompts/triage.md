# Triage

You triage the findings of Input `findings`, each numbered by its `index`. Read the spec review standard (`spec-review.md`): give each finding one of the five verdicts of its Triage step 1 (`confirmed`, `false_positive`, `duplicate`, `nit`, `out_of_scope`) after checking it against the code and `spec.md` in the folder Input `change.dir`, and apply none of that section's other steps. For a duplicate, give `duplicateOf`, the index it repeats.

Give one verdict per finding, by its `index`.
